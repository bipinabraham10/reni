BIRTHDAY WEBSITE V4 — MATTER FIELD / LAVENDER INTERACTION EDITION

What it uses
- Three.js: procedural WebGL matter/nebula background + depth particles
- Lavender particle field with cursor attraction/repulsion
- Scroll-responsive background movement so “SCROLL / MOVE TO DISTURB” is functional
- GSAP + ScrollTrigger: cinematic entrance, scroll reveals, image parallax and interaction
- Lenis: smooth scrolling
- Custom requestAnimationFrame cursor physics
- Interactive Orbit object in the intro: animated celestial core, orbit rings, hover response, and click-to-enter-memories
- Fixed hero heading clipping: descenders such as the “y” now have enough vertical room
- Responsive mobile fallback

Design direction
- Black / charcoal base with restrained lavender light and particles
- Editorial, spatial and cinematic rather than a generic starfield
- Inspired by the restrained interactive/editorial approach of Aaron J. Cunningham, but this page is an original design for this experience.

Run
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Open index.html in a modern browser.

Internet access is needed for Google Fonts and the CDN-hosted libraries.
